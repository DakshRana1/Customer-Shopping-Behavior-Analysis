# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

Customer Shopping Behavior Analysis is a data analytics project focused on understanding customer purchasing patterns, shopping preferences, and business trends using Python, SQL, and Power BI.

The objective of this project is to transform raw customer transaction data into actionable business insights that can help organizations improve marketing strategies, customer engagement, and sales performance.

---

## 🎯 Business Objectives

- Analyze customer demographics and purchasing behavior
- Identify top-selling product categories
- Understand seasonal shopping trends
- Evaluate the impact of discounts and promo codes
- Analyze customer loyalty and subscription behavior
- Discover revenue-driving factors
- Build an interactive dashboard for business decision-making
